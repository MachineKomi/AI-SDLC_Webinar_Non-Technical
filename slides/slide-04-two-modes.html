The Core Distinction

Prototype Mode vs. Production Mode

🧪 Prototype Mode

"Try things. Break things."
Optimized for learning and exploration.

  • ✓ Fast iteration, loose gates
  • ✓ Accept higher risk for speed
  • ✗ Not safe for production data

🏭 Production Mode

"Prove it works."
Optimized for reliability and auditability.

  • ✓ Plan-first, stage-by-stage
  • ✓ Small batches, explicit gates
  • ✓ "Done" = evidence, not vibes
