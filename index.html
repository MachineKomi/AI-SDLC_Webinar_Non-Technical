The Core Distinction

Prototype Mode vs. Production Mode

🧪 Prototype Mode

"Try things. Break things."
Optimized for learning and exploration.

  • ✓ Fast iteration, loose gates
  • ✓ Accept higher risk for speed
  • ✗ Not safe for production data

🏭 Production Mode

"Prove it works."
Optimized for reliability and auditability.

  • ✓ Plan-first, stage-by-stage
  • ✓ Small batches, explicit gates
  • ✓ "Done" = evidence, not vibes

Proof over Promises

What "Done" actually looks like.

It's not a thumbs up. It's a document with objective evidence: tests passing, checks green, runtime behaviour validated.

The "Evidence Gate"

A unit is done only when acceptance criteria pass, tests and checks are green, and the validation report is updated with exact commands and results.
